## 📋 Project Overview
A fully scoped, multi-tenant (Domain Separated) B2B ITSM application engineered for Telecom Providers. This project demonstrates an end-to-end incident lifecycle, bridging external customer alerts, self-service portals, and internal IT fulfillment teams using ServiceNow best practices.

## 🛠️ Technologies & Features Demonstrated
- **Architecture & Security:** Scoped Application, Domain Separation, Custom Roles (RBAC), ACLs, User Criteria.
- **Backend Automation:** Flow Designer, Business Rules, SLAs (Stop/Cancel logic).
- **Frontend & UX:** Service Portal, Record Producers, Client Scripts, UI Policies, Asynchronous `GlideAjax`.
- **Integrations:** Scripted REST APIs (JSON), Inbound Email Actions (Regex, Data Parsing).
